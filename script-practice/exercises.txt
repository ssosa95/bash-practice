hello.sh — print a greeting, then ask for the user's name and greet them by name:
#!/bin/bash

echo "Welcome to the greeting script!"
read -p "Enter your name: " name
echo "Hello, $name."

sysinfo.sh — print the following using only Bash commands, no Python:

Current date and time — hint: date is a command
Current user — hint: whoami is a command
Current directory
Hostname of the machine — hint: hostname is a command

#!/bin/bash

date
whoami
pwd
hostname
